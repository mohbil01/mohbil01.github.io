# mohbil01.github.io

Personal site for mathematics and theoretical physics. It uses plain HTML and CSS and can be served by GitHub Pages directly from the repository root.

- `index.html` contains the homepage and introduction.
- `notes/index.html` lists handwritten lecture-note PDFs by Tripos part. The links use the original exports in `IA/`, `IB/` and `II/`.
- `part-iii/index.html` lists the exam papers by course. Its links point to the PDFs in `Theoretical Physics Papers/`.
- `styles.css` is shared by both pages. Future posts and project pages can use the same stylesheet.

To preview, serve the repository root with any static HTTP server and open its local address. Include the linked PDFs when committing the site for GitHub Pages.
